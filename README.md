# Web - Service

## Опис проєкту
Цей веб-застосунок призначений для виконання трудомістких обчислювальних задач, а саме розв’язування систем лінійних рівнянь

Застосунок підтримує балансування навантаження між кількома серверами для забезпечення стабільної роботи при великій кількості запитів.

---

## Основні можливості
- Обмеження максимальної складності задач (за часом або кількістю невідомих).
- Відображення прогресу виконання задачі в реальному часі.
- Перегляд історії виконаних задач та стану поточних.
- Можливість скасувати або запустити нову задачу.
- Авторизація користувачів (через HTTPS).
- Балансування навантаження між мінімум двома серверами застосунків.

---

## Додаткові можливості
- Черга запитів при перевантаженні системи.
- Автоматичне горизонтальне масштабування (нові сервери або контейнери).
- Панель адміністратора для моніторингу навантаження на сервери.

---

## Мета проєкту
Забезпечити ефективне обслуговування трудомістких запитів із можливістю масштабування, балансування навантаження та контролю ресурсів.
